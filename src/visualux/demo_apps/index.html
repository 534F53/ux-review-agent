Try an evaluation

Copy a scenario URL into your VisualUX configuration and use the task shown above. Configure your own image-capable model; browsing these apps needs no model or credentials.

The demos contain fixed synthetic data. “Reset demo data” in each app clears records created in that browser context. Clear and confusing variants have the same underlying data and operations. Expected answers and evaluation manifests are not served here.

Use independent sessions and the same task/model settings when comparing variants. Scores and findings are generated from actual runs; no app has a scripted evaluation result.
