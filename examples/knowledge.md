# Fieldwork domain reference

A lab is a group of devices in one location. Lab North is the current location.
A serial number identifies a unit. Synthetic test serials have the form
TEST- followed by four digits. A warning threshold is a whole temperature in
degrees Celsius, from 1 through 120. Device names are human-readable references.

Non-secret values for a test device:

- Device name / Reference: review-device-01
- Serial number / Code: TEST-0001
- Temperature warning threshold / Value: 80

These values are task inputs, not evidence that a device already exists or that
creation succeeded. The application must show the resulting state.
